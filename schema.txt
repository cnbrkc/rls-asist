### 3.1 — `app.py` (ANA UYGULAMA)

**Boyut:** ~550 satır, tek dosya monolitik yapı  
**Framework:** Streamlit  
**Sorumluluk:** Tüm iş mantığı + UI + API yönetimi

#### Bölüm Haritası (Sırayla):

| Satır Aralığı | Bölüm | Açıklama |
|---|---|---|
| 1–15 | **Import'lar** | streamlit, google.genai, json, os, re, time, wave, tempfile, uuid, base64, datetime |
| 17–70 | **KAYIT DOSYASI YARDIMCILARI** | `kayitlar.json` CRUD işlemleri (max 5 kayıt, 24 saat ses ömrü) |
| 72–115 | **PROMPT YÜKLEME YARDIMCILARI** | `.txt` prompt dosyalarını oku + dinamik şablon doldurma |
| 117–125 | **API KEY YAPILANDIRMASI** | `st.secrets["GEMINI_KEYS"]` → dict (mail: key) |
| 127–165 | **AYARLAR VE SABİTLER** | Cooldown süreleri, model listeleri, Türkçe aylar |
| 167–230 | **YARDIMCI FONKSİYONLAR** | markdown temizleme, JSON parse, temp dosya yönetimi, sekme aktif tutma |
| 232–370 | **SmartRouter SINIFI** | Akıllı API yönlendirme, ban sistemi, hata yönetimi |
| 372–400 | **SAYFA AYARLARI + UI INIT** | page_config, session_state başlatma |
| 402–460 | **SOL MENÜ (Sidebar)** | Ses seçimi, key listesi, ban durumu, geçmiş üretimler |
| 462–500 | **ANA ARAYÜZ** | Video upload, analiz notları, süre, ton seçimi, ÜRET butonu |
| 502–600 | **ÜRETİM PIPELINE** | 4 adımlı üretim akışı (analiz → metin → threads → ses) |
| 602–700 | **SONUÇLAR UI** | Medya oynatma, metin gösterimi, düşünce zinciri, yeniden ses üretimi |

#### `SmartRouter` Sınıfı Detayı:

```
SmartRouter
├── __init__()              → blacklist dict başlatma (session_state)
├── _is_banned()            → mail+model kombinasyonu banlı mı?
├── _ban()                  → Ban ekle (scope: model/key/combo)
├── _retry_delay_cikar()    → Hata mesajından retryDelay parse et
├── _parse_hata()           → Hata tipini belirle (quota/404/503/free_tier)
├── _handle_hata()          → Hata aksiyonu (break_model / devam)
├── _make_request()         → Model×Key matrisinde döngü, ilk başarılıyı döndür
├── metin_uret()            → JSON schema ile structured output + opsiyonel Google Search
├── ses_uret()              → TTS (text-to-speech) → WAV dosyası
└── video_analiz_et()       → Video bytes + prompt → analiz metni
```

#### Model Stratejisi:

| Görev | Modeller | Öncelik |
|-------|----------|---------|
| Video Analiz | `gemini-3.6-flash` → `gemini-2.5-flash` | En zeki modeller |
| Metin Üretimi | `gemini-3.6-flash` → `gemini-2.5-flash` → `gemini-3.5-flash-lite` → `gemini-3.1-flash-lite` | Zeki + yüksek kota yedekler |
| Ses (TTS) | `gemini-2.5-flash-preview-tts` | Tek model |

#### Cooldown/Ban Sistemi:

| Hata Tipi | Cooldown | Scope |
|-----------|----------|-------|
| Free tier yok (limit: 0) | 7 gün | Model bazlı (tüm key'ler) |
| 429 / Quota | retryDelay veya 60sn | Key+Model combo |
| 503 / Unavailable | 15 dk | Key+Model combo |
| 404 / Not found | 24 saat | Model bazlı (tüm key'ler) |
| Diğer | 5 dk | Key+Model combo |

#### Üretim Pipeline (4 Adım):

```
┌─────────────────────────────────────────────────────────┐
│ ADIM 1: VIDEO ANALİZ                                    │
│  Girdi: video bytes + analiz notları + süre             │
│  Model: VIDEO_ANALIZ_MODELLERI + Google Search          │
│  Çıktı: analiz_metni (marka, görsel akış, viral veri)  │
├─────────────────────────────────────────────────────────┤
│ ADIM 2: METİN ÜRETİMİ                                   │
│  Girdi: analiz + üretim notları                         │
│  System: kurallar.txt + sistem_talimati.txt             │
│  Schema: beyin_firtinasi, veri_kilitleme, oz_elestiri,  │
│          seslendirme_metni, reels_aciklamasi,           │
│          reels_hashtagleri, kapak_basliklari            │
│  Model: METIN_MODELLERI (arama KAPALI)                  │
│  Çıktı: JSON veri                                       │
├─────────────────────────────────────────────────────────┤
│ ADIM 3: THREADS ÜRETİMİ                                 │
│  Girdi: reels_aciklamasi                                │
│  System: threads_promptu.txt                            │
│  Schema: threads_aciklamasi (STRING)                    │
│  Model: METIN_MODELLERI (arama KAPALI)                  │
│  Fallback: reels_aciklamasi[:500]                       │
│  Çıktı: threads_aciklamasi                              │
├─────────────────────────────────────────────────────────┤
│ ADIM 4: SES ÜRETİMİ (TTS)                               │
│  Girdi: seslendirme_metni + seçilen ses                 │
│  Model: gemini-2.5-flash-preview-tts                    │
│  Format: WAV (mono, 16-bit, 24kHz)                      │
│  Çıktı: .wav dosyası (temp)                             │
└─────────────────────────────────────────────────────────┘
```

#### JSON Response Schema (Metin Üretimi):

```json
{
  "type": "OBJECT",
  "properties": {
    "beyin_firtinasi":    "STRING  → Strateji planı (CoT adım 1)",
    "veri_kilitleme":     "STRING  → Kesin rakamlar listesi (CoT adım 2)",
    "oz_elestiri":        "STRING  → Öz denetim (CoT adım 3)",
    "seslendirme_metni":  "STRING  → TTS metni (hedef kelime ±%10)",
    "reels_aciklamasi":   "STRING  → 5 katmanlı caption (hashtagsiz)",
    "reels_hashtagleri":  "ARRAY<STRING> → Tam 5 hashtag",
    "kapak_basliklari":   "ARRAY<{ana: STRING, alt: STRING}> → 5 alternatif"
  },
  "required": ["tüm alanlar"]
}
```

#### Session State Anahtarları:

| Key | Tip | Açıklama |

| `blacklist` | dict | Ban kayıtları {key: timestamp} |

### 3.2 — `kurallar.txt` (STATİK PROMPT)

**Rol:** Ana içerik üretim kural seti (system prompt'un ilk parçası)  
**Boyut:** ~250 satır  
**Dinamik mi?:** HAYIR (sabit metin)

#### İçerik Bölümleri:

| Bölüm | Konu |
|-------|------|
| §1 KİMLİK | otoXtra persona, hedef kitle, ton (samimi halk ağzı) |
| §2 GİRDİ VE HESAPLAMA | Kelime formülü: süre × 2.8 → en yakın 5'in katı, ±%10 tolerans |
| §3 ÇIKTI FORMATI | 4 bölüm sırası: Seslendirme → Açıklama → Hashtag → Kapak |
| §4 SESLENDİRME KURALLARI | Doğal akış, cümle yapısı, bilgi yoğunluğu, duygu/ton, pozisyon alma, TTS format, paylaşılabilirlik, yasaklar |
| §5 CAPTION KURALLARI | 5 katman (Hook → Bağlam → İlişkilendirme → Hot Take → CTA), SEO, biçim |
| §6 HASHTAG KURALLARI | Tam 5 etiket, dağılım (marka/geniş/niş/özel), yasaklı etiketler |
| §7 ENGAGEMENT BAIT YASAĞI | Kırmızı/Gri/Yeşil liste |
| §8 KAPAK BAŞLIK KURALLARI | Ana (2-4 kelime BÜYÜK) + Alt (5-10 kelime), 5 alternatif |
| §9 GENEL İLKELER | Niş sınırı, içerik tipleri |

### 3.3 — `sistem_talimati.txt` (DİNAMİK ŞABLON)

**Rol:** System prompt'un ikinci parçası (kurallar.txt'den sonra eklenir)  
**Dinamik mi?:** EVET — 6 placeholder var

#### Placeholder'lar:

| Placeholder | Kaynak | Örnek Değer |
|-------------|--------|-------------|
| `{guncellik_talimati}` | `guncellik_talimati.txt` işlenmiş hali | "Bugün: 27 Temmuz 2026..." |
| `{sure_saniye}` | Kullanıcı input | `30` |
| `{kelime_sayisi}` | Hesaplama: round(30×2.8/5)×5 | `85` |
| `{min_kelime}` | max(5, int(85×0.9)) | `76` |
| `{max_kelime}` | int(85×1.1) | `93` |
| `{bilgi_orani}` | Ton seçimine göre | "Her 2 cümleden 1'i..." |

#### İçerik Bölümleri:

| § | Konu |
|---|------|
| 1 | Süre ve kelime sayısı (KRİTİK) |
| 2 | Bilgi-eğlence oranı (tona göre) |
| 3 | Kullanıcı notları önceliği |
| 4 | Zorunlu düşünce zinciri (CoT) — beyin_firtinasi, veri_kilitleme, oz_elestiri |
| 5 | Çıktı formatı (JSON şema uyumu) |

#### Bilgi-Eğlence Oranları:

| Ton Seçimi | Oran |
|------------|------|
| 🎭 Eğlence Ağırlıklı | 1/4 bilgi, 3/4 eğlence |
| ⚖️ Dengeli (varsayılan) | 1/2 bilgi, 1/2 eğlence |
| 🧠 Bilgi Ağırlıklı | 3/4 bilgi, 1/4 eğlence |
| 📊 Teknik Odaklı | 9/10 bilgi, 1/10 eğlence |
